### 💻 Projects

- 🚀 **[Social Media](https://github.com/Harshthakur0729/Social-Media)**  
  A backend-based project where users can upload images, and an AI automatically generates suitable captions for them.

- 🧩 **Dynamic Web**  
  A full stack project where users can fully customize the website according to their preferences. They can change text, adjust sizes, add images, and create new routes.  
  An admin panel is provided to manage and control all these customizations easily.

- 🔒 **Media Chat**  
  Ek web-based chat website jahan aap real-time mein text, voice message, audio aur video bhej aur receive kar sakte ho.  
  Saare media aur messages client-side encrypt ho ke bheje jaate hain, isliye privacy aur security maintained rehti hai.  
  Features mein media preview, group/one-to-one chat, delivery/seen status aur message replies shamil hain.
